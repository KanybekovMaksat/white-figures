# White Figures

Скилл для Claude Code: делает рилс-притчу на 15 секунд без слов. Белые безликие фигурки на чёрном стекле, левая сторона против правой, мораль, победа в лаймовом свете, в конце «Смотрите подробности в описании». На выходе mp4 1080×1920, обложка и текст описания для Instagram.

Формат подсмотрен у вирусных роликов с белыми человечками (десятки миллионов просмотров) и переложен на палитру школы Codify.

## Что внутри

| папка | что там |
|---|---|
| `SKILL.md` | пять шагов: сюжет → заготовка и музыка → картинка → описание → сборка |
| `engine/` | three.js-движок: рендер по кадрам в headless Chromium → ffmpeg |
| `engine/scenes/` | пять готовых сцен-образцов (башни, родители, телефон и робот, лестницы, призраки) |
| `references/` | правила вида, какой образец брать, шаблон брифа и описания |
| `tools/` | сборка звука, обложка, музыка (ElevenLabs) |
| `sfx/` | звуковые эффекты |
| `scripts/` | `scaffold.sh` (новая серия) и `finish.sh` (сборка в «Готовые рилсы») |

## Установка

```
git clone https://github.com/KanybekovMaksat/white-figures.git ~/.claude/skills/white-figures
npm i -g playwright && npx playwright install chromium
```

Нужны node 20+, ffmpeg и ключ ElevenLabs для музыки: строка `ELEVENLABS_API_KEY=…` в файле `.env` в папке проекта.

## Запуск

В Claude Code в папке проекта: `/white-figures 3 притчи про …` или просто «сделай притчу про …».

Призыв в описании и палитра заточены под Codify (дети 7–14, робототехника и программирование, Бишкек). Для своего бренда поправьте `references/description.md` и `references/look.md`.
